2. Your mount

cli_debrid doesn't download or store files. A mount tool shows your debrid/usenet files as a normal folder, and both cli_debrid and your media server read from that folder. Set one up first if you haven't: mount setup guide.
💡 cli_debrid can't see the path?
The path is checked from inside cli_debrid's container, so it has to be mapped in your docker-compose.yml. cli_debrid and your media server must see the mount (and the symlink folder) at exactly the same path. The easiest way is to pass

/mnt:/mnt
into both containers.

cli_debrid makes a tidy folder of symlinks pointing into your mount, and your media server scans that folder. Works with Plex, Jellyfin and Emby.
💡 Want my advice?
If you are starting fresh - I recommend using a Symlinked library if you are on Linux, otherwise you will need to use a Plex Library (especially if you are watching Anime content).

If you already have an rclone mounted library in Plex and are not having issues - continue using it.

If you are having issues with an rclone mounted library (items not scanning in, Anime not recognized by Plex) consider either starting a new Symlinked library or converting your library to Symlinks (done later in Step 5)

cli_debrid looks up shows, seasons, episodes and release dates. Both keys are free.

Used for posters, digital/physical release dates and Discover. Get it at themoviedb.org/settings/api. Use the short API Key, not the long "API Read Access Token".

Without a TVDB key, cli_debrid looks shows and movies up on Trakt instead. Trakt is also needed for Trakt-based content sources. Create an application at Trakt Applications. All you need to add is a Name, and the Redirect URI which is:
