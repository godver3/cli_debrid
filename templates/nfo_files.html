NFO Files

From 3 December 2026 Plex numbers TV shows by TMDB, while cli_debrid names your episode files by its own metadata (TVDB numbering, or the episode order you picked for a show). Where the two disagree, Plex shows the wrong episode titles. NFO files next to your episodes carry cli_debrid's title, plot and air date for exactly the episode in each file. Plex, Jellyfin, Emby and Kodi all read them.

NFO files need Symlinked/Local file management: in Plex mode cli_debrid has no library folder to write them to.
  • Turning this on writes tvshow.nfo and one .nfo per episode file under , keeps them up to date as episodes are added, upgraded, removed or renumbered, and (with Plex) switches the TV library to an agent that reads them, then refreshes it.
  • Turning it off puts Plex's previous agent back and deletes the NFO files cli_debrid wrote. NFO files you made yourself are never changed or deleted.
Library Rewrites every show's NFO files, then sets up Plex and refreshes the library.
Plex

The agent cli_debrid makes, cli_debrid NFO + Plex Series, reads the NFO file first, then Plex Series for anything the NFO doesn't say (cast, artwork, Discover), then local media. Shows keep their Plex identity, so watch history and collections stay. Needs Plex Media Server 1.43.1 or newer.
