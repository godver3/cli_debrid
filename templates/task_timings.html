Task timings and intervals are displayed based on the running program. Customize intervals using the input fields (in seconds) and save your preferences. The "Default" value never changes - it's the original program default. "Custom" shows any saved custom interval. "Configured" shows the currently active interval (custom or default). Saved intervals apply on program restart unless live updates are successful.
