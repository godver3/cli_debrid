Move your cli_mount library to the built-in mount without downloading anything: jobs keep their IDs, folders and file names, so cli_debrid's records, your symlinks and Plex keep working. Every step copies: cli_mount is never changed, so you can switch back at any time, and jobs added in the meantime can be copied back to it.

1. Run the built-in mount alongside cli_mount

It mounts on its own path (Settings tab → Mount path, e.g. /mnt/clid) while cli_mount keeps serving. Set your usenet servers in the Settings tab first.

2. Import cli_mount's library

Reads cli_mount's job list and its saved file maps (no usenet traffic). Safe to run again: jobs already imported are skipped. Encrypted archives can't be imported.

0 = all. Start with a few hundred to try it; running Import again carries on and skips jobs already imported.

    

    
3. Compare

      
Reads random usenet files through both mounts and compares size and the bytes at their start, middle and end. Debrid folders are checked by name and size only (reading them would request debrid links twice).

Virtual folders

    
Extra folders at the top of the mount, each listing the jobs that match all its filters (a name regex and a files regex together match either). Useful in Plex mode: point a Movies library at one folder and a TV library at another. Add Movies + TV Shows fills in the docs' Content routing filters, so every release lands in exactly one of the two. Sizes take 10GB / 500MB, last_added takes 7d / 12h, protocol takes usenet or debrid.
