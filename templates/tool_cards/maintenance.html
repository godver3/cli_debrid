cli_mount DB Cleanup

Remove entries for a specific debrid provider from cli_mount's entries.db and items.db using infohash matching. Mixed folders (containing files from multiple providers) are rebuilt with only non-provider files kept.

⚠ Stop cli_mount before running a live cleanup. Dry run is safe to run anytime.

Backfill NZB File Names

Rename collected NZB items in the database and cli_mount to the structured NZB naming format (Title (Year) - {imdb-...} - Version - (Original.Release.Name)). Requires NZB file naming to be enabled in settings.

Cleanup My Plex Watchlist and Other Plex Watchlists

Removes all Collected items from My Plex Watchlist and all configured Other Plex Watchlists. If an item appears in multiple watchlists it will be removed from all of them.

Reset Battery Show Status Cache

Forces all shows in the battery DB to be re-fetched from TVDB/Trakt on the next run. Use this to fix incorrect show statuses (e.g. "Ended" instead of "Canceled"). After running this, run "Update show status (ended/airing)" on the Automation page.
