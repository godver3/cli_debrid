Optional: Subtitles

Clyde can find subtitles for everything it collects, so you don't need Bazarr. This step is optional: skip it and you can turn subtitles on later in Settings → Subtitles.

How it works

  • When an item is collected, Clyde searches the subtitle providers for each language you pick.
  • It picks the subtitle made for your exact file first (an OpenSubtitles file-hash match, so it's in sync), then one for the same release group, then the same Blu-ray or streaming source. A subtitle for a different episode or movie is never used.
  • Languages the file already has as an embedded text track can be skipped (Settings → Subtitles → Probe for embedded subtitles).
    • {% if subs.plex_mode %}
  • Direct Mount: the media is on a read-only mount, so subtitles are uploaded to the Plex item and show up in its subtitle menu.
    • {% else %}
  • Symlinks mode: subtitles are saved next to the library file (Movie (2020).en.srt), so Plex, Jellyfin and Emby all pick them up.
    • {% endif %}
  • Tools → Subtitle Manager shows what's missing, lets you search and pick by hand, fill in your whole library at once, and import your Bazarr settings.
{% if subs.bazarr %}
You already send new items to Bazarr. You can keep it, or turn subtitles on here and use Subtitle Manager → Import from Bazarr later to bring over its languages and logins.
{% endif %}

Do you want Clyde to handle subtitles?

Comma-separated codes, in the order you prefer, e.g. eng or eng,spa (fre, ger, pt-BR, zho …).

OpenSubtitles.com recommended

The largest catalog, and the only one with file-hash matches. Searching works without an account, but downloading needs a free login: sign up at opensubtitles.com. A free account can download about 20 subtitles a day; Clyde pauses it when that runs out and uses the other providers.

More providers optional, free

Each one adds more subtitles, especially for TV. Leave a field blank to skip it. Podnapisi, Gestdown (Addic7ed) and TVsubtitles are used without a key.
Make a free account at subdl.com, then open your account page → API.
Make a free account at subsource.net, then open your profile → API.

Already have a library? After setup, Tools → Subtitle Manager → Search all missing fills it in.
