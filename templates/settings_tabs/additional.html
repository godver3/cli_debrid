+

AI Assistant

+

Enable the AI Butler chat widget on all pages. Requires OpenClaw to be installed and configured. Works best with a paid AI API (e.g. OpenAI, Anthropic, Gemini) — free tier models may lack the context window or tool-calling capability needed for reliable responses.

URL of your OpenClaw instance. OpenClaw handles AI provider selection and session memory.

Bearer token for OpenClaw authentication. Leave blank if OpenClaw has no auth configured.

OpenClaw agent ID to use (default: main).

Send proactive alerts via your notification channels when the AI Butler detects issues (stuck queues, high blacklist rate, errors, etc.).

How often the AI Butler runs background health checks. Minimum 300 (5 minutes). Default 900 (15 minutes).

Allow the AI to read your full settings schema and suggest or apply configuration changes via the chat. When enabled, the AI can send APPLY_SETTING blocks that let you update settings with a single click, and it is given the list of all writable settings keys. Disabling this means the AI will still answer questions but cannot propose or apply any setting changes — useful if you want a read-only assistant.

Allow the AI Health Monitor to run background checks every few minutes and push plain-English alerts to your notification channels (Telegram, Discord, etc.) when it detects problems such as stuck queues, high blacklist rates, excessive errors, or a large database. Disabling this stops all automatic health checks and alerts — you can still ask the AI about health manually in the chat.

Allow the AI to recommend content based on your watch history and collected library, and add items directly to your wanted list via the chat with a single click. When enabled, the AI receives a summary of your recently watched and collected titles for context, and can generate ADD_TO_LIBRARY cards. Disabling this removes watch/library context from the AI prompt and disables the add-to-library action — the AI will still answer general questions but won't know what you have watched.

Record significant user actions (running wanted sources, triggering upgrade scans, pausing queues, adding library items) in the background and surface pattern summaries to the AI. With this enabled, the AI can notice that you run a source every morning and suggest automating it, or spot that you frequently remove the same type of item from the blacklist and recommend a settings change. Disabling this stops all habit recording and removes the pattern summary from the AI context — no data is deleted, it just won't be updated or shown to the AI.

When enabled, the AI receives your full configuration (up to 15 000 chars), extended log tails (up to 20 000 chars), upgrade activity history, and recent notification logs — giving it the most complete picture of your setup for accurate diagnostics and suggestions. Secrets (API keys, tokens, passwords) are always redacted regardless of this setting. When disabled, the AI only receives a short config excerpt (2 000 chars) and a brief log tail (3 000 chars), which reduces context sent to the AI provider but may result in less accurate advice.

Apply a Plex label to items added to your library via the AI Butler.

Fixed: apply the same label to all AI Butler additions.

Label to apply to all items added via AI Butler. Comma-separated for multiple labels.

Download SKILL.md

Downloads a pre-configured OpenClaw skill file with your URL and API token already filled in. Drop it into ~/.openclaw/skills/ on your OpenClaw machine, then reload OpenClaw. Your agent will then be able to answer questions about your library from external messengers like Telegram or Discord.

Note: This skill requires cli_debrid to be publicly accessible — it cannot work via an internal IP only. Exposing cli_debrid publicly means anyone with your token can control it, so User Management must be enabled before downloading. For best security, use OIDC/SSO (e.g. Authentik) rather than local accounts.
