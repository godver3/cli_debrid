Version Settings

Configure scraping profiles and preferences

How Scraping Versions Work: These scraping settings will be used to calculate a total score for each release, and to filter items in or out of the results. Weights are used to emphasize or de-emphasize specific traits. Use the Scraper Tester to verify that your results match what you expect.
  • Filter In - Include only results with these terms.
  • Filter Out - Include no results with these terms.
  • Preferred Filter In - Increase score of results with these terms.
  • Preferred Filter Out - Reduce score of results with these terms.

{% elif key == 'foreign_language_penalty' %}

Penalty for a release tagged with a different audio language (e.g. GERMAN for an 'en' version), multiplied by Language Weight. Subtitle tags (SWESUB, VOSTFR, NORDiC) don't count; MULTi, Dual Audio and DL (dual-language) releases are exempt. For a title whose original language isn't the version's (e.g. a Korean show on an 'en' version), releases tagged DUAL or with the version's language get a small tiebreaker bonus instead (this amount × Language Weight, at most 50; half for a bare MULTi/DL). Untagged releases are never penalized. 0 disables both. A cached release is still taken before any uncached one whatever its score, so the penalty alone can't keep out a tagged release that is the only cached match (e.g. a freshly aired episode whose only cached copy is a foreign dub). To drop tagged releases instead, set a large penalty (e.g. 1000) together with a Minimum Scrape Score above 0 (Settings → Scraping; the Delayed Scrape Minimum Score only applies with delayed scrape).

{% elif key == 'audio_description_penalty' %}

Penalty for an audio-description release (e.g. 'with Audio Description'), whose audio is narrated for blind viewers. The default 10000 ranks one below every other release, so it is only picked when nothing else is available; with a Minimum Scrape Score set (Settings → Scraping), it falls below that and is dropped instead. Use a negative number to prefer them instead, or 0 to treat them like any other release.

{% endif %} {% endif %}
