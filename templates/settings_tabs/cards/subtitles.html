Subtitle Settings

Download subtitles when an item is collected. Works in both modes: Symlinked/Local writes a sidecar file next to the library file. In Direct Mount, Plex gets the subtitle uploaded to its item (the mount is read-only); Jellyfin, Emby and Silo get a sidecar file when the mount accepts one, else an upload (Jellyfin and Silo only). Adds a few seconds per file. Manage and search subtitles under Tools → Subtitle Manager.

OpenSubtitles.com account (free). Needed to download from OpenSubtitles.com, the largest provider.

OpenSubtitles password for subtitle downloads

Languages to get subtitles in. Pick from the list; the order doesn't matter. A red entry is a code that isn't a recognised language: remove it and pick the language from the list.

None of these need a captcha. Every selected provider is searched and the best match wins: a file-hash match first (exact release, already in sync), then same release group/source. Matches for the wrong episode or movie are never downloaded. Ctrl/Cmd-click to select several.

Free key from your subdl.com account (API section). Large catalog, strong for TV and releases OpenSubtitles has little for.

Free key from your subsource.net profile (API section).

Styled ASS/SSA and image (PGS/VobSub) subtitles make most Plex/Jellyfin/Emby clients transcode. When on, downloaded ASS/SSA subtitles are converted to plain SRT, and an embedded image or styled track doesn't count as having that language, so an SRT is fetched.

Plex users: turn off Plex's own subtitle analysis

In Plex go to Settings → Library and set Generate voice activity data to never. Plex uses it to auto-sync subtitles, but it reads every file in full, which on a debrid/usenet mount means downloading your whole library in the background. Sync here only reads a few short samples.

Moving from Bazarr? Tools → Subtitle Manager → Import from Bazarr copies its languages, providers, login and sync settings.

Always fetch separate subtitle files, even when the video already has a good embedded track in that language. Off (default): an embedded text track (not forced, not commentary, not a format that makes players transcode) counts as having the language.

Skip languages the file already has as an embedded track (forced tracks don't count). If every language is embedded, the search (and Bazarr notification) is skipped. If the add-time ffprobe playability check is on, its result is reused, so there's no second read of the file; otherwise this reads the file header once (needs ffprobe). In Direct Mount it only uses the add-time check's result.
