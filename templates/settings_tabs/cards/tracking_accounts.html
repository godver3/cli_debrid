Scrob

Scrob is an optional self-hosted Trakt alternative (ellite/scrob) used for Scrob-based content sources (Lists, Collection, Special Lists). Enter your instance's base URL and an API key from Settings → Connections → API Key in the Scrob UI. This connection is shared by every Scrob content source below — no need to re-enter it per source.

The API key covers everything needed to sync content into cli_debrid. Username and password are optional and only used so cli_debrid can also remove items from Scrob when you delete them from your library — Scrob's API only allows deletions from a logged-in session, not an API key. Leave these blank if you don't need that.
