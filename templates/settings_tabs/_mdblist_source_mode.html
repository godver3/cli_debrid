Works with any public MDBList list and needs no API key.'), ('api_watchlist', 'My MDBList Watchlist', 'api.mdblist.com/watchlist/items'), ('api_user_list', 'Username + List Name', 'api.mdblist.com/lists/{username}/{listname}/items'), ('api_list_id', 'List ID', 'api.mdblist.com/lists/{listid}/items') ] %} {% endfor %}

The three API options call the MDBList API directly and require an MDBList API key (Additional Settings → MDBList).

{# --- json_url: comma separated list URLs --- #}

Comma-separated list URLs. '/json' is appended automatically unless the URL already ends in '.json'.

{# --- api_watchlist: nothing to configure beyond the API key --- #}

Fetches the watchlist of the account that owns the configured MDBList API key. No further configuration needed.

{# --- api_user_list: username + list name --- #}

Both values come straight out of the list URL: mdblist.com/lists/username/list-name.

{# --- api_list_id: numeric list id(s) --- #}

Numeric MDBList list ID. Several IDs can be given, separated by commas.
