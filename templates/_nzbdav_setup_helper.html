NzbDAV setup helper

What you do vs. what's automatic: you type your paths/URL below and the tool writes the config files for you — but you copy them to your host and run the shown docker compose commands yourself (cli-debrid runs in a container and can't create other containers). The only step this tool performs automatically is checking/creating the NzbDAV categories in section 2. Fields are prefilled from your saved settings; blank fields fall back to the placeholders.
