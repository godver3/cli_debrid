### Preset collections for Plex
- **Settings → Media Server → Plex Collections → Preset collections**: ready-made Plex collections you switch on one by one, like Kometa's defaults. Clyde builds them from titles already in your library. Nothing is requested or downloaded
  - **Seasonal:** Christmas, Halloween, Thanksgiving, Valentine's Day, New Year's Eve
  - **Charts:** Box Office Blockbusters, Top Rated, Trending This Week, Popular (movies and shows, kept in rank order)
  - **Decades & Genres:** 1980s Movies, 1990s Shows... and, optionally, one collection per genre
  - **Awards:** Oscar Best Picture, Oscar Best Animated Feature, Palme d'Or, Emmy Outstanding Drama and Comedy Series winners
  - **Studios:** Pixar, Walt Disney Animation, DreamWorks Animation, Illumination, Studio Ghibli, Marvel Studios, DC, Lucasfilm, A24, Blumhouse
- Lists come from TMDB (needs the TMDB API key) and Wikidata; decades and genres come from your Plex library
- Collections refresh once a day (new **Preset collections** task on the Automation page), when you save the settings, and with **Run Now**
- A collection only appears once you have enough matching titles (**Minimum titles**, default 3)
- Switching a preset off removes the collection Clyde made. If you already had a collection with the same name, Clyde only adds to it: it never removes your items or deletes it

### Fixes
- **Plex verification no longer re-checks your whole backlog every few hours.** The "recent files" check picked up every unverified file ever linked instead of the last 6 hours, and compared them with only Plex's 100 newest items. After a big relink (like the TorBox zip packs re-added in 0.9.1) hundreds of episodes that were already in Plex failed over and over, each one starting another Plex folder scan, until they were marked failed. Now only recent files are checked that way, and the full check (whole library) picks up the rest. A file that's relinked counts as new again
