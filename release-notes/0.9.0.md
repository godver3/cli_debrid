### cli_debrid is now called Clyde
- New name and logo across the app: header, browser tab, favicon, home-screen icon, onboarding, help pages and notifications
- Only the name changed. Updating needs nothing from you: your settings, database, logs, environment variables and folder paths all stay the same
- The Docker image is still `godver3/cli_debrid`, and every build is also published as `godver3/clyde` with the same tags. Either name works
- The default logo is the new Clyde icon. The **Color Icon** and **Plex-Inspired** logos are still in Settings → UI Settings
- New box set and Adaptive List collection posters use the Clyde icon. Posters already in Plex are left as they are
- For the AI assistant (MCP) connection, new setups show the server name `clyde`. Existing connections keep working
- The home page terminal still says `user@cli_debrid:~$`, as a nod to where it all started

### New
- **New movies are searched on their release day**
  - A movie is first searched at midnight at the start of its release date (plus **Movie Airtime Offset**). It used to wait until midnight at the end of that day, when releases were usually already out
  - If nothing is found that day, it's searched again every hour. Those retries don't count toward the wake limit, so a movie can't be blacklisted any sooner than before
  - Shows are unchanged: episodes still go by their air time
- **Upgrade Hub searches with your own scrapers**
  - Each scan searches your configured scrapers for a batch of library items, 50 by default. Items never checked go first, then the ones checked longest ago, so a daily scan works through the whole library over time and finds better releases that appear months later
  - Zilean is no longer required. Zilean and the NZB indexer feed are optional extra sources under **Bulk Sources**, which now defaults to **None (scrapers only)**. If you've run Upgrade Hub scans before, it stays on **Both** until you change it
  - New **Search With My Scrapers** and **Items Searched Per Scan** settings on the hub's Settings tab
- **Search Recent Releases button on the Upgrade Hub**
  - Searches your scrapers for a better release of every collected item released in the last N days (default: your Release Age setting), up to 2,000 items per run
  - Starts right away and adds what it finds to your current results
- **Release Age setting**
  - Sets which newly collected items get the upgrade window, by how recently they were released (default 7 days). It was fixed at 7 days before

### Changed
- **All upgrade settings are on the Upgrade Hub**
  - A new **Upgrading** group on the hub's Settings tab holds turning upgrading on, the release age, the upgrade window, the score improvement needed, the score to stop at, the extra search after release, and removing the old copy
  - Settings → Scraping and Settings → Queues & Upgrades link there instead. Your existing values are kept
- **Cache badges work beyond Real-Debrid**
  - TorBox users see whether a candidate is cached, from TorBox's own cache check. Real-Debrid still uses Phalanx
  - Auto-queue queues cached candidates first and skips ones reported not cached, unless you accept uncached results
- **The Upgrading queue no longer holds up other queues**
  - It runs every 5 minutes and searches for at most about 2 minutes per run. Items it doesn't reach go first on the next run, and each item is still searched at most once an hour
- **Scheduled Upgrade Hub scans run in the background**, so they don't delay other scheduled tasks

### Fixes
- **4K upgrades of the same release were skipped**
  - A result whose name was 95% similar to the current file was treated as the same file, so "Movie.2025.2160p.WEB-DL-GROUP" never replaced "Movie.2025.1080p.WEB-DL-GROUP". Now only the same release is skipped
- **Saving Settings could turn upgrading off**
  - The Settings page switched upgrading off whenever its checkbox wasn't on the page
