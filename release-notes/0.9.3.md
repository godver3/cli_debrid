### Database page fixes
- **Scrolling after a filter showed the wrong rows.** After changing a filter, sort or columns, scrolling down loaded rows from the old filter. If the first view fit on one page, scrolling never loaded more at all
- **Select All now really selects everything.** It used to tick only the rows loaded on screen, and rows that scrolled out of view were silently unticked. Ticks now stay put, and **Select all … matching** picks every row the filter matches
- Titles with `&`, `<` or quotes showed wrongly from page 2 on, and the Source badge could land in the wrong column
- "Unique" counted only the current page; it now covers the whole filter. Row numbers no longer restart at 1 on later pages

### Faster Database page
- Opening the page no longer loads the table twice, and each page is about half the size
- Scrolling is smoother: fewer things run on every scroll
- Rows per page now goes up to 1,000 (a saved 2,000 or 5,000 becomes 1,000)
