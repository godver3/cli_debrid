### Database page fixes
- **Scrolling after a filter showed the wrong rows.** After changing a filter, sort or columns, scrolling down loaded rows from the old filter. If the first view fit on one page, scrolling never loaded more at all
- **Select All now really selects everything.** It used to tick only the rows loaded on screen, and rows that scrolled out of view were silently unticked. Ticks now stay put, and **Select all … matching** picks every row the filter matches
- Titles with `&`, `<` or quotes showed wrongly from page 2 on, and the Source badge could land in the wrong column
- "Unique" counted only the current page; it now covers the whole filter. Row numbers no longer restart at 1 on later pages

### Picking up files added outside Clyde
- **No more junk imports.** The "scan mount for external adds" setting imported Clyde's own leftovers: cache-check probes and failed grabs. It now skips anything Clyde added itself, and waits until a new folder has been seen twice and is 10 minutes old before importing it
- **Works with more mounts.** If the path points at a cli_mount, Decypharr or built-in mount root, the scan now looks inside `__all__`. It also scans your usenet mount, including NzbDAV's category folders
- **Direct Mount support.** In Direct Mount mode the scan asks your media server to scan each new folder, and the library sync adds it to Clyde
- **Fewer scans and notifications.** A season pack now triggers one media server scan and one notification instead of one per episode. This also applies to the Zurg webhook
- `.m4v` files are now picked up, and on the built-in mount the scan follows its file-type setting
- Folders that are still filling up, imports that only partly worked, and a flaky mount listing no longer make the scan give up early or import a mount's worth of old content. It logs when it gives up, and why it skipped a run
- A corrupt scan state file is restored from a backup instead of quietly starting over

### Streaming-only debrid accounts
- **Stop adding to a fallback provider without losing what's on it.** Tick **Streaming only** next to a fallback in Settings → Required → Debrid Providers. Clyde stops sending new releases there, while files already on that account keep playing through the built-in mount and stay visible in the debrid library and repair tools. Before, removing a provider was the only way to stop grabs, and with the built-in mount that broke playback of every file it held

### Faster Database page
- Opening the page no longer loads the table twice, and each page is about half the size
- Scrolling is smoother: fewer things run on every scroll
- Rows per page now goes up to 1,000 (a saved 2,000 or 5,000 becomes 1,000)

### Mount page
- **Queue pages fit on one line.** The built-in mount's queue showed a button for every page, hundreds on a big queue. It now shows Prev and Next, the first and last page and the pages around the current one

### Old theme code removed
- **Metadata Debug: Recreate and Delete now show their result.** The buttons used to work through a hidden copy of the old page, so their messages never appeared, and Recreate didn't refresh what you were looking at
- **Connections page loads less.** It no longer builds a hidden copy of the old layout and polls it twice a second
- Queues, Logs, Library and Onboarding pages no longer download their stylesheet twice. The Library movie and show pages no longer skip the browser cache for one stylesheet on every visit
- Overlays, Badges, Layout Builder and Scraper Tester load their styles with the page instead of just after it, so there is no flash of unstyled content
- Leftover code from the old classic theme is gone from Scraper, Add Media, Statistics, PhalanxDB and the shared page scripts
