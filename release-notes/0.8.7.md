### New
- **Direct Mount works with Jellyfin and Emby**
  - Pick **Jellyfin / Emby** as Direct Mount's media server in Settings or onboarding, next to Plex and Silo. Point its Movies and TV libraries at the mount's Movies and TV Shows folders
  - New downloads are scanned in, collected once the server lists them, and removals drop out, as with Plex and Silo
  - Plex-only features (labels, collections, reported issues, Plex watch history) stay off; overlays work
- **Subtitles in Direct Mount with Jellyfin, Emby or Silo**
  - Saved as a file next to the episode when the mount takes it (the built-in mount does), and the server is told to pick it up
  - On a read-only mount they're uploaded to Jellyfin or Silo instead. Jellyfin: turn off "Save subtitles into media folders" in the library's settings. Emby takes no uploads, so it needs a mount that accepts the files

### Changed
- **Plex mode is now called Direct Mount**
  - Your media server reads the mount directly, so the old name no longer fit. Only the name changed: your setting, library and everything else stay the same

### Fixes
- **Sample files no longer added as a second episode**
  - With the built-in mount, some usenet episodes got an extra library entry pointing at the release's ~1-minute sample. In Plex it showed as a second version, and picking it played only the clip
  - Started with 0.8.0. Samples and trailers are now skipped when collecting
  - Sample entries already in your library aren't removed automatically. Look for files ending in `.sample` or `-sample`, or starting with `sample-`, next to an episode
- **Jellyfin and Emby in Symlinked/Local mode**
  - Checking that symlinks reached the library found no libraries on current Jellyfin, so it never confirmed anything. It reads the libraries properly now
  - Emby TV shows and episodes lost their IMDb id when cli_debrid read the library. Fixed
- **SDR releases no longer rejected as HDR**
  - With HDR off, any release with "SDR" in its name was thrown out as HDR content, for example Netflix SD rips of older shows. They're now judged like any other release
- **Version names checked on requests**
  - Requests and Scraper adds only accept versions you've configured. An unknown name used to add an item no version could ever find
  - A request with no version selected now shows an error instead of "Already have"
- **Trakt not connected**
  - No more "No refresh token available" / "Failed to refresh Trakt token" errors every few minutes when no Trakt account is connected. Lookups that would use Trakt now skip it quietly, with one note in the log

### Security
- **Requested folders stay inside your library**
  - The folder chosen in a request dialog could contain `..` and put symlinks outside the library, for any signed-in user including requesters
- **User management**
  - Changing your own password needs your current one
  - New users can only get the Admin, User or Requester role
  - An admin can't delete the account they're signed in with
