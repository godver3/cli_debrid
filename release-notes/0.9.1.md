### Save Plex's episode details before 3 December
- On **3 December** Plex stops using TheTVDB. After that it can only fill in TV episodes from TMDB, so the titles, descriptions and air dates Plex shows today (and anything you edited by hand) are gone the next time a show refreshes
- **Tools → NFO Files → Snapshot Plex now** reads every episode of the TV library that holds your symlinks and saves what Plex shows for it as an NFO file next to the episode, plus a `tvshow.nfo` with the show's IDs
- **Plex isn't changed, and you don't need to turn NFO files on.** The files wait until you switch Plex (or Jellyfin, Emby or Kodi) to an agent that reads NFO files
- NFO files you made yourself, and the ones Clyde writes for an NFO mode, are never replaced. Upgraded episodes keep their snapshot NFO, and deleting an episode deletes its NFO too
- Every snapshot is also kept in `plex_metadata_snapshot.db`, with its date, so a later snapshot doesn't overwrite an earlier one. You can write any of them back into the library, or delete the snapshot NFO files, from the same page
- Needs Symlinked/Local file management: in Plex (Direct Mount) mode there's no library folder to write to

### NFO files for your TV library
- **Tools → NFO Files** (Symlinked/Local). From 3 December Plex numbers shows by TMDB, while Clyde keeps numbering episodes the TVDB way (aired, DVD, absolute, alternate...) or by a TMDB episode group, whichever order you picked. NFO files next to your episodes make Plex follow Clyde's numbering, so every order keeps working, including ones Plex never offered. Three modes:
  - **Off** (default): no NFO files, everything as before
  - **Shows with a changed episode order**: NFO files only for shows you set to another order in Show options or Manual Assign, written as soon as you change it. Every other show looks exactly as Plex makes it
  - **All shows**: every show gets NFO files. This also fixes default-order shows that TMDB numbers differently (many anime)
- **Looks like Plex's own agent:** an episode Plex already numbers the same way gets a minimal NFO, so Plex still fills in its title, description, thumbnail and cast. Only episodes Plex would mix up get the right episode's details: title, description, air date, thumbnail, director, writers and guest stars. The show's title, artwork, cast and ratings stay Plex's
- **Plex set up for you, or left alone:** by default, turning NFO files on creates a Plex agent ("Clyde NFO + Plex Series": NFO first, then Plex Series, then local media), switches the TV library that reads your symlinks to it, and refreshes it. Shows keep their Plex identity, so watch history stays. Untick **Switch my Plex TV library to the NFO agent** to only write the files and leave Plex exactly as it is; you can switch later with **Set up Plex agent**. Turning NFO files off puts the previous agent back and deletes only the NFO files Clyde wrote
- **Check a show** compares every episode file of a show with what Plex shows for it, lists wrong or missing episodes, and has a Fix button (rewrite the NFOs and refresh in Plex). For each show you can also choose to follow the mode, always write full details, or never write NFO files
- **Convert entire library** rewrites every show's NFOs and re-applies the Plex agent in one go. NFOs follow episodes as they're added, upgraded, removed or renumbered. Jellyfin, Emby and Kodi read the same files

### Built-in mount
- **TorBox packs stored as one zip now work.** TorBox keeps a big torrent (100+ files) as a single .zip, and a hash someone else cached that way comes back zipped even though Clyde asks for it unzipped. Nothing inside could be matched or streamed. Clyde now lists the files inside the zip and the mount reads each one directly, without unpacking
- **A TorBox CDN server that's down no longer stops playback.** When the nearest server refuses connections, links are made on another region's server instead (west US, west Europe, Nordics), and the mount swaps a dead link for a fresh one instead of retrying it for hours
- Releases whose only videos are a type the mount hides (like `.ts`) are skipped at pick time instead of failing in Checking over and over
- Two torrents with the same name get "Name" and "Name (2)" on the mount; Checking now finds the files in whichever folder the mount really used
- Usenet imports keep to their time limit and run 8 at a time, so one stuck import can't hold up the rest
- **Moving from cli_mount:** switching adds the file types your library already uses (like `.ts`) to the built-in mount's list, so those episodes don't vanish, and Compare warns about them beforehand

### Finding and matching releases
- **Anime split into seasons now finds seasons 2 and up in packs numbered straight through** (01, 02 ... 39). Revolutionary Girl Utena only ever got season 1: S2E1 is file 14 in those packs, and Clyde only looked at files numbered 1
- **Single episodes can come from a cached season or complete-series pack.** Packs named with a season's own name ("Survivor Borneo Complete Season 1") or "Collection" were thrown out on the title check
- **Country versions:** shows whose title has no country tag (Survivor, US) no longer take other countries' versions (Survivor.AU, .IL, .ZA). The Scraper page now searches The Traitors (IN) with its country tag too, so UK/US/AU results are filtered out there as well
- **Shows with sub-series** (Pokémon): a sub-series' releases (Horizons) no longer pass as the main show through its aliases, and files with no season ("Show - 0053") are only linked to the one episode they are, not to episode 53 of every season
- **Pack files from another episode order** are no longer linked as a second version of the wrong episode. A pack numbered differently from the show (Pokémon's aired-order pack on a DVD-order show) could repoint an episode to another episode's file and show extra versions in Plex

### Queue and Adding
- **An indexer that's out of downloads no longer freezes the rest of the show.** The waiting episode parks until the indexer's limit resets, and the Queue page says so: "Waiting: NinjaCentral out of downloads, retrying in 23 min"
- The Queue page's "Indexer:" label shows the indexer the NZB was actually grabbed from
- A usenet download that's only slow is no longer marked not wanted by the health check when the built-in mount handles it; only proof that a release is bad counts

### Magnet Assign
- **Skip specials:** clear and ignore every Season 0 episode in one click so specials get no files and aren't added to Wanted
- Confirm works for very long shows (Pokémon, 1,240 episodes) instead of failing with "Request Entity Too Large"
- Opening the file preview for a TorBox torrent you already had no longer deletes it from your account
- Episodes with no title in TVDB's absolute order no longer break matching

### Fixes
- **Deleting large shows is much faster:** removing hundreds of episodes batches the database delete, checks `tvshow.nfo` once per show folder, and runs one media server scan and trash empty per season folder instead of once per episode
- **Security:** release names, file names and other text from indexers, TMDB and Trakt are escaped everywhere they're shown, so a release named with HTML can't run script in the UI
- The Scraper page shows the S02 / E01 tags as tags again, instead of raw `<span ...>` text
- Subtitles: the harmless OpenSubtitles.org error on every run and Gestdown's "No show id found" are no longer logged as errors
