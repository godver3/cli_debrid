### Changed
- **Versions settings page is easier to read**
  - Each version shows a one-line summary (resolution, HDR, size range, anime filter, fallback) while collapsed, so you can compare versions without opening them
  - Settings are grouped under headings, and Filter In / Filter Out / Preferred In / Preferred Out are labelled lists with their own Add buttons
  - Rename, Duplicate, Export and Delete are in a `⋯` menu on each version; the add buttons are one **Add Version** menu
  - Nothing about how settings are saved has changed
- **Connections page uses compact cards**
  - One row per connection, Torrent Scrapers and Usenet Indexers in separate sections, one "checked" time for the page
  - Subscription expiry turns amber within 14 days and red once passed; Newznab daily usage shows on its card

### New
- **Scraper Stats: grabs per day**
  - A small bar chart per scraper, with failed grabs in red and a tooltip per day
  - Columns that are 0 for every scraper are hidden, and success rates from fewer than 20 grabs are faded
- **Usenet indexer limits on the Rate Limits card**
  - Each enabled Newznab indexer's API hits and grabs for the day, against its limits, and when they reset
- **Move to the built-in mount from Decypharr**
  - Import now reads the newer metadata format Decypharr saves, so a Decypharr library moves over without re-downloading, like a cli_mount one
  - In Direct Mount, Compare and Switch said "cli_mount's mount path isn't known". They now use the Direct Mount path

### Fixes
- **Renaming or deleting a version**
  - Renaming "1080p" also renamed items on similarly named versions like "1080p Remux". Only the exact version changes now
  - Deleting a version left behind items the reverse parser had assigned to it (marked `*`)
  - Rename and delete now also update the Reverse Parser default, terms and order, the box-set grab version and the usenet repair version
  - A version that fell back to the deleted one no longer falls back to itself, and a content source keeps its own on/off setting for the version items move to
  - Names that are taken, blank, `None`, or contain `*` or slashes are refused
  - The Reverse Parser default could revert to a deleted or renamed version on the next Save
  - Importing a version from a file stopped working after adding, renaming or deleting one
- **Missing files re-wanted correctly**
  - A "1080p Remux" copy counted as a 1080p copy, so a missing 1080p item was dropped instead of searched for again
- **"Do not add watched items" skipped the wrong movies**
  - Watching a TV episode could skip a movie with the same TMDB number. Those lookups are also much faster now
- **Scraper Stats**
  - Episodes that reused another episode's season pack were logged as "Unknown". They now get the scraper that found the pack, and existing entries are fixed at startup
  - Manual grabs are always counted as Manual
  - The daily chart's totals match the table for 7- and 30-day ranges
- **Diagnostics**
  - TVDB and TMDB calls were missing from the API summary
  - "View Full Summary" and "View All Calls" opened off-screen on the Performance dashboard
- **Overlay conditions using `IS NOT NULL` never showed the element**
- **Hung network calls**
  - Plex sign-in and token checks, Telegram and ntfy notifications and some TMDB/Trakt lookups could wait forever on a stalled server. They time out now

### Removed
- **The unused `/video` player page**
  - No page linked to it, and each stream started an unlimited ffmpeg transcode

### Behind the scenes
- **Version matching**
  - Item versions are the name plus an optional reverse-parser `*`/`**` marker. Rename, delete, the usage check, maintenance and the library analyser used `LIKE '1080p%'` / `'%1080p%'`; they now compare `RTRIM(version, '*')` to the exact name and keep the marker
  - The database helpers raise on errors instead of returning 0, so the config is never changed after a failed database update
- **Request timeouts**
  - 12 `requests` calls had no timeout. They now use 15s (30s for the Plex split in force-match)
- **Watch history**
  - The movie lookup was `type = 'movie' AND imdb_id = ? OR tmdb_id = ?`; AND binds tighter, so any row with that TMDB id matched. Now parenthesised
  - New indexes on `(imdb_id, season, episode)` and `(tmdb_id, season, episode)` replace a full-table scan per lookup (up to three per episode)
- **Overlay conditions**
  - `_evaluate_condition` replaced `' NOT '` before `' IS NOT NULL'`, producing a SyntaxError that hid the element. The replacements run in the right order now
- **API call logging**
  - `api_calls.log` is now written from `HTTPAdapter.send`, so every outbound request is logged once whichever code makes it (the TVDB client's own session, direct `requests` calls). The mount engine's API, the Usenet mount URL and Phalanx DB are left out
- **Scraper Stats**
  - A grab with no source takes the source of the latest earlier grab of the same torrent hash or NZB guid (manual grabs excepted); startup backfills old "Unknown" rows the same way
  - New indexes on `info_hash` and `nzb_guid` keep that lookup and the backfill fast
  - New endpoints: `/statistics/api/scraper_stats/trend` and `/debug/api/indexer_quota_info` (admin only)
- **Built-in mount import**
  - Upstream Decypharr stores each job's `.meta` as `0xB1` + three zstd regions (header, column-wise segment map, message ids) and converts older protobuf files on startup. The importer reads both; the disk-space estimate counts v2 files at 4x their size
  - The old mount's path comes from Plex → `mounted_file_location` in Direct Mount (onboarding hides `original_files_path` there), and from `original_files_path` in Symlinked/Local; each falls back to the other
  - `zstandard` is now listed in requirements (it was already installed through Flask-Compress)
- **Code removed**
  - A supervisor block disabled with `and False` since 0.6.46, repeated imports in `main.py`, `rate_limit_check`, 11 functions nothing called, and `logging.basicConfig` calls that ran at import in three modules
- **Tests**
  - New tests for version rename/delete, the watch-history query, overlay conditions, request logging, indexer limits, Scraper Stats source inheritance and trend, and the Decypharr v2 import (with files written by Decypharr's own encoder)
