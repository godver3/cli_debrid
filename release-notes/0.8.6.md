- New **Settings → Export / Import**: save your setup to a file and load it on another install. Personal details (URLs, paths, keys, accounts) never travel, imports only add, and anything new arrives switched off
- New **Silo** media server option, next to Plex and Jellyfin/Emby, in both Symlinked/Local and Plex mode: library scans, removals, Now Playing, stream protection, show precache, recommendations, embedded subtitle info and the onboarding folder check
- New **Silo Requests** content source: what people request in Silo gets added to cli_debrid
- New **Report a bug** button in the top bar (admins): describe the problem, and it adds your version, setup and links to freshly uploaded (redacted) logs, including the built-in mount's or cli_mount's. Open it as a prefilled GitHub issue or copy it for Discord
- The **Release notes** button shows these notes in the app again
- Debrid Manager opens on Health & Repair when the mount serves your debrid files, and loads faster
- Mount speed test no longer fails on the first click after a quiet spell
- README: built-in mount up top and a clearer Getting Started
- Poster overlays stop re-uploading the same posters every hour: shows without a status in the main database, sibling episodes holding an old poster link, and episodes that tie on quality no longer look "changed" on every sync
- Rating badges refresh again across the whole library (oldest first, a few dozen titles per sync) instead of the same handful each week
- Poster cleanup only deletes old overlay versions Plex reports as unused, on items cli_debrid overlaid. It used to sweep every uploaded poster in Plex's folder, and Overlay Settings now spots a Plex data path pointing at the wrong folder and offers the right one
- New items no longer hold up other overlays while waiting for Plex to index them
- Overlays page: new **Last Sync** card shows when overlays last synced, what it rendered and how many applied posters it sent back for a re-render, and warns when that happens on every sync
- Overlays page: the eye button on **Cleaned Up** previews the next poster cleanup, listing the files it would delete without touching anything
