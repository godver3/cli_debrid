- New **Settings → Export / Import**: save your setup to a file and load it on another install. Personal details (URLs, paths, keys, accounts) never travel, imports only add, and anything new arrives switched off
- New **Silo** media server option, next to Plex and Jellyfin/Emby, in both Symlinked/Local and Plex mode: library scans, removals, Now Playing, stream protection, show precache, recommendations, embedded subtitle info and the onboarding folder check
- New **Silo Requests** content source: what people request in Silo gets added to cli_debrid
- New **Report a bug** button in the top bar (admins): describe the problem, and it adds your version, setup and links to freshly uploaded (redacted) logs, including the built-in mount's or cli_mount's. Open it as a prefilled GitHub issue or copy it for Discord
- The **Release notes** button shows these notes in the app again, and new releases post their notes to the Discord release notes channel
- Debrid Manager opens on Health & Repair when the mount serves your debrid files, and loads faster
- Mount speed test no longer fails on the first click after a quiet spell
- README: built-in mount up top and a clearer Getting Started
- Poster overlays stop re-uploading the same posters every hour: shows without a status in the main database, sibling episodes holding an old poster link, and episodes that tie on quality no longer look "changed" on every sync
- Rating badges refresh again across the whole library (oldest first, a few dozen titles per sync) instead of the same handful each week
- Poster cleanup only deletes old overlay versions Plex reports as unused, on items cli_debrid overlaid. It used to sweep every uploaded poster in Plex's folder, and Overlay Settings now spots a Plex data path pointing at the wrong folder and offers the right one
- New items no longer hold up other overlays while waiting for Plex to index them
- Poster cleanup works on Windows and non-Docker installs (it looked for the database in a Docker-only folder), and Jellyfin overlays compare ratings the same way they render them
- Overlays page: new **Last Sync** card shows when overlays last synced, what it rendered and how many applied posters it sent back for a re-render, and warns when it keeps re-rendering the same posters sync after sync
- Overlays page: the eye button on **Cleaned Up** previews the next poster cleanup, listing the files it would delete without touching anything. If cli_debrid isn't allowed to delete in Plex's folders, the preview says so and shows the command that fixes it, and the cleanup logs one warning instead of an error per file. The Cleaned Up card also flags a wrong Plex data path or a cleanup that couldn't delete
- Plex collection poster previews: no more permission error at every start on Docker installs, and **Regenerate previews** rebuilds them again
- SSO login: the post-login redirect only goes to pages on cli_debrid, an SSO account can no longer take over a local account that is already linked to someone else or is matched only by an unverified email, and the SSO settings no longer send the client secret back to the browser
- Debrid-Link: cache checks list your seedbox once per search instead of once per result, and flood/maintenance errors are handled as rate limits and outages
- Movie box sets: cleanup only removes collections it created or postered (it could delete a same-named collection you made yourself), also removes ones whose movies are all gone, a TMDB outage no longer marks movies "not in a collection" for good, and 1080p + 4K copies of one movie count once
- Migrate between usenet providers: finished or cancelled jobs no longer freeze the tool, it works with the built-in mount as source or target and Zurg as a target, cli_mount items keep their release names instead of becoming UUIDs, NzbDAV downloads send the API key, failed and duplicate source items are skipped, "skip items already at target" works for cli_mount and can be turned off, only one transfer runs at a time, a reload resumes the progress view, and it lists what to change afterwards
- Manual blacklist: Save All no longer turns shows blocked for some seasons into all seasons, blocking one season of a fully blocked show keeps it fully blocked, and the list is saved safely so a crash mid-save can't empty it
- Performance dashboard: CPU and memory charts show the latest samples (they showed the oldest in the window), and time windows are right on hosts not set to UTC
- Reverse parser: usenet items are parsed as usenet, and Apply keeps each item's real state
- External mount scan: a mount that briefly lists only some folders no longer causes old content to be imported as new
- AIOStreams: a "1080p" line is no longer read as 1080 seeders
- Security: release titles from indexers are no longer inserted as raw HTML on the Scraper, Scraper Tester, Reverse Parser and Database pages, so a malicious title can't run script in your browser. Plex Labels tools, Metadata Lookup and several debug tools now need an admin, not just any logged-in user. Create a Symlink's file browser no longer lets `..` step outside the allowed folders
- Upgrades no longer remove the old torrent or NZB while other episodes still play from it (season packs), both after a normal upgrade and from Upgrade Hub's **Run cleanup**. **Clear hub queue** leaves upgrades already in progress alone
- Tools → Convert Library to Symlinks no longer deletes an episode whose file is missing just because another episode of the show exists; it goes back to Wanted. Its progress counters show real numbers
- Tools → Version Propagator keeps genres, runtime, custom folders, tags and content source on the new copies, and no longer adds items without a year again on every run
- Tools → Rclone Mount to Symlinks no longer changes your saved symlink path while it scans
- Tools → Run Task lists every task from the scheduler (two were dead, about 25 missing), and errors like "already running" show properly. Background tools that fail now show an error instead of a green success
- Tools → Symlinks: Duplicate Symlink Targets checks every folder layout; Resync runs in the background; Modify Symlink Base Paths only matches whole folders; Verification Queue shows the real unverified count
- Tools → Get Collected: All and Recent are hidden in Symlinked/Local mode, where they did nothing but reported success
- Tools → Fix Missing IMDb ID updates every episode of the show, and refuses a TMDB ID that matches both a movie and a show
- Create a Symlink: shows its success or error message, adds rows that repair, resync and verification can use, asks your media server to scan the new file, and warns when no IMDb ID means cli_debrid won't track it
- Trakt friends: removing one also stops its content source straight away. Plex user tokens are saved readable only by cli_debrid, and two sign-ins finishing together no longer lose one
